# Similar Movies App

## Overview
Similar Movies App is web application that allows users to search for a movie and view a list of similar movies based on their selection. The application uses **The Movie Database (TMDB) API** to fetch movie data and recommendations.

This project was built following the official TMDB API documentation and does not use any third-party TMDB wrappers or libraries.


## Features
- Search for movies by title
- Display search results from TMDB
- Select a movie to view similar movies
- Direct API calls
- Responsive UI built with React


## Technologies Used
- JavaScript
- HTML
- CSS
- TMDB REST API
- React


## API Usage
This project uses the Movie Database (TMDB) API according to the official documentation:

- https://developer.themoviedb.org/reference/intro/getting-started


## How to Use
1. Start by searching for your movie title.
2. Click on the movie title to view similar movies.


## Notes
To run this project, you must provide your own TMDB API key.
